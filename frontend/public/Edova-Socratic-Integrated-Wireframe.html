Symbolic Math Solver — 5-Step Algebraic Derivation

Step 1: Assign variable & Length Breadth = x, Length = 2x + 1
Step 2: Area formulation Area = Breadth · Length → x · (2x + 1) = 528
Step 3: Standard Quadratic Form 2x² + x − 528 = 0
Step 4: Split middle term (AC Method: 2 · -528 = -1056; 33 · -32 = -1056) 2x² + 33x − 32x − 528 = 0 → (2x + 33)(x − 16) = 0
Step 5: Physical Root Selection x = 16 (Accepted) or x = -16.5 (Discarded — distance cannot be negative).
Breadth = 16 m, Length = 33 m
